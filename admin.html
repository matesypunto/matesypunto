Ingresar al panel

Pegá tu clave de GitHub. Se pide una sola vez por dispositivo.

¿Cómo saco la clave?
  1. En GitHub, entrá a Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Nombre: panel mates. Vencimiento: el más largo que te deje (o "No expiration").
  3. En Repository access elegí Only select repositories → matesypunto.
  4. En Permissions → Repository permissions → Contents elegí Read and write.
  5. Tocá Generate token, copiá la clave y pegala acá.

No compartas esta clave con nadie: permite modificar tu página.
